1) **Planejamento de Usabilidade (método DECIDE)**

| D | Avaliar se o aplicativo é fácil de usar e atende às necessidades das pessoas idosas. |
| :---: | :---- |
| **E** | Verificar se os usuários conseguem navegar pelo aplicativo, encontrar as funções e entender as informações.  |
| **C** | Utilizar questionários, observação dos usuários e avaliação heurística. |
| **I** | Realizar testes de usabilidade do aplicativo e testes com idosos reais. |
| **D** | Solicitar consentimento, respeitar a privacidade e não divulgar informações pessoais dos participantes. |
| **E** | Analise de dificuldades e melhoria nestes pontos |

1. Termo de consentimento
Documento utilizado para informar os participantes sobre a pesquisa, seus objetivos e como os dados serão utilizados. A participação será voluntária.

2. Questionários
Formulários utilizados para coletar informações sobre a experiência dos usuários, suas dificuldades, preferências e opiniões sobre o aplicativo.

3. Tabela de observação
Utilizada durante os testes para registrar o comportamento dos participantes, suas dificuldades de navegação, dúvidas e facilidade para realizar as tarefas.

4. Formulário de avaliação heurística
Utilizado para avaliar a interface do aplicativo com base em princípios de usabilidade, como facilidade de navegação, clareza das informações, consistência e prevenção de erros.
